# NRSC510
This is Isabel Lewin's GitHub repository for the 2026 NRSC510 Topics in Neurodata course 

Stored in this repository are R scripts that were created to analyze data for the NRSC510 final project 

Data used for analysis was generated by Alex Lawson from the Rosin Lab at UBC 

Link to Borealis Dataverse site containing Alex's dataset: [Dataverse-IL-NRSC510](https://demo.borealisdata.ca/dataverse/Dataverse-IL-NRSC510)
